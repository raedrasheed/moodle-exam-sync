# قبول التجربة المحلية

تنفّذ هذه القائمة على الموقعين الفعليين قبل اعتماد التشغيل. اختبارات PHPUnit لا تتحقق من تسجيل LTI في متصفحك أو شبكتك أو إضافاتك الخارجية.

| التجربة | النتيجة المطلوبة |
| --- | --- |
| فحص `check.php --peer` في الموقعين | دورا المصدر والهدف صحيحان ولا توجد أخطاء إعداد |
| مقرر بمدرس وطالبين، اختبار جديد مع خيار التنفيذ البعيد | يظهر اختبار واحد جاهز في الهدف ورابط LTI واحد في الرئيسي |
| أسئلة ثابتة وصور ومرفقات وسؤال عشوائي من تصنيف محدد | تعمل الملفات ويختار السؤال من المجموعة المقصودة؛ لا تنتقل الأسئلة غير المتعلقة |
| دخول الطالب عبر الرابط | يدخل بالحساب المرتبط نفسه، دون طلب إنشاء حساب يدوي |
| دخول المدرس عبر الرابط | يرى تقارير وتصحيح الاختبار ولا يستطيع تعديل المحتوى المتزامن |
| معاينة المدرس قبل الطالب | لا تثبت محتوى الاختبار بسبب المعاينة |
| تعديل سؤال قبل أي محاولة | تُطبّق نسخة أحدث، ويبقى الرابط ثابتًا، وتُخفى نسخة الهدف السابقة |
| مجموعات واستثناء زمني لطالب واستثناء عدد محاولات لمجموعة | تظهر القيم والأعضاء الصحيحون في الهدف، وتبقى صحيحة عند إعادة المزامنة |
| تعطيل تسجيل طالب في الرئيسي | يتوقف قبوله لمحاولة جديدة، وتُحدّث عضويته في الهدف |
| إخفاء نشاط LTI أو تقييد إتاحته في الرئيسي | يمنع بدء محاولة جديدة حتى باستخدام رابط الهدف مباشرة |
| محاولة طالب وإرسال الإجابات | تحفظ المحاولة في الهدف وتصل الدرجة إلى بند LTI في الرئيسي |
| إخفاء الدرجة/تحديد وقت إظهارها/تعديلها يدويًا في الهدف | ينتقل التحديث مع سياسة الإظهار، ولا ترجع درجة قديمة فوقه |
| فحص مجموع درجات المقرر | تُحتسب الدرجة مرة واحدة، وتصنيف بند LTI وأوزانه صحيحة |
| قطع الاتصال بعد بدء محاولة | تظل المحاولة القائمة قابلة للاستمرار؛ يبدأ الإرسال المؤجل عند عودة الاتصال |
| قطع الاتصال قبل محاولة جديدة | لا تبدأ محاولة دون تأكيد المصدر، وتظهر رسالة قابلة للفهم |
| تعديل المحتوى بعد قبول محاولة | لا يُستبدل المحتوى في الهدف؛ أنشئ اختبارًا جديدًا لتغيير النسخة المعتمدة |
| إعادة تشغيل cron والضغط على إعادة المزامنة | لا تتكرر المقررات أو روابط LTI أو حسابات المستخدمين |
| شروط إكمال المقرر والأنشطة المرتبطة باختبار التأليف | تضبط يدويًا لتشير إلى LTI عند الحاجة وتُجرّب بحساب طالب |

## تجميد دخول متروك

يثبت المحتوى عند قبول بدء المحاولة قبل إنشائها، لإغلاق سباق التعديل مع بدء الاختبار. إذا قُبل الدخول ثم انقطع الطلب قبل وجود أية محاولة فعلية، يستطيع المدير تشغيل الأمر التالي في **المصدر** فقط:

```bash
php public/local/examsync/cli/recover.php --uuid=EXAM_UUID --release-unused-freeze
```

يوقف الأمر القبول الجديد، ويطلب من الهدف تأكيد خلو الاختبار من المحاولات، ثم يرفع التجميد ويصف نسخة جديدة للمزامنة. وجود محاولة فعلية يمنع العملية. عند فشل الاتصال يبقى القبول موقوفًا؛ عالج السبب وأعد الأمر. يظهر UUID في سجل الربط أو عنوان الحزمة؛ أداة `status.php` تعرضه دون عرض أسرار.

## نتيجة القبول

سجّل إصدار Moodle وPHP ونوع قاعدة البيانات في الموقعين، أنواع الأسئلة التي جُرّبت، زمن انتقال الدرجة، ونتيجة كل بند. احذف أو غطّ أي رموز تسجيل ومفاتيح قبل مشاركة صور الأخطاء.
